LOAN DEFAULT RISK DASHBOARD - DAX MEASURES
================================================

IMPORTANT:
Replace 'Loan_Default_Risk_Dataset' with your actual Power BI table name if it is different.

1. Total Loans
----------------
Total Loans =
COUNTROWS('Loan_Default_Risk_Dataset')


2. Total Loan Amount
---------------------
Total Loan Amount =
SUM('Loan_Default_Risk_Dataset'[Loan_Amount])


3. Outstanding Amount
----------------------
Outstanding Amount =
SUM('Loan_Default_Risk_Dataset'[Outstanding_Amount])


4. Defaulted Loans
-------------------
Defaulted Loans =
CALCULATE(
    COUNTROWS('Loan_Default_Risk_Dataset'),
    'Loan_Default_Risk_Dataset'[Default_Status] = "Default"
)


5. Default Rate
----------------
Default Rate =
DIVIDE(
    [Defaulted Loans],
    [Total Loans],
    0
)

Format this measure as Percentage.


6. High Risk Customers
-----------------------
High Risk Customers =
CALCULATE(
    DISTINCTCOUNT('Loan_Default_Risk_Dataset'[Customer_ID]),
    'Loan_Default_Risk_Dataset'[Risk_Category] = "High"
)


7. Average Credit Score
------------------------
Average Credit Score =
AVERAGE('Loan_Default_Risk_Dataset'[Credit_Score])
