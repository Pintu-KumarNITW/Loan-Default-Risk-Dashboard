# Loan Default Risk Dashboard

## Project Overview

The **Loan Default Risk Dashboard** is an interactive Power BI data analytics project designed to analyze loan portfolio performance and identify patterns associated with loan defaults and customer risk.

The dashboard provides a consolidated view of loan performance, default behavior, customer risk, credit scores, employment categories, income groups, debt-to-income ratios, and monthly default trends.

---

## Project Objectives

- Analyze overall loan portfolio performance
- Monitor total loans and total loan amount
- Track outstanding and defaulted loans
- Calculate and monitor the default rate
- Identify high-risk customers
- Analyze loan defaults by loan type
- Analyze defaults by employment type
- Compare default behavior across income groups
- Analyze customer risk categories
- Study the relationship between credit score and loan amount
- Analyze debt-to-income ratio and default risk
- Monitor monthly default trends

## Dashboard Analysis

### 1. Loan Portfolio Overview

The KPI section provides a quick overview of the complete loan portfolio, including total loans, loan amount, outstanding amount, defaulted loans, default rate, high-risk customers, and average credit score.

### 2. Default Analysis

The dashboard compares defaulted and non-defaulted loans and provides a breakdown of defaults by:

- Loan Type
- Employment Type
- Income Group
- Loan Status
- Customer Risk Category

### 3. Customer Risk Analysis

Customer risk is analyzed using:

- Risk Category
- Credit Score
- Loan Amount
- Debt-to-Income Ratio
- Default Status

This helps identify customer segments that may require additional risk assessment.

### 4. Trend Analysis

The monthly default trend visual helps monitor changes in loan defaults over time and identify periods with higher or lower default activity.

### 5. Geographic Analysis

The dashboard includes location-based analysis to identify states or locations with higher numbers of defaulted loans.
